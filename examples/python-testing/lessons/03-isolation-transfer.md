# 第三课：不联网也能测依赖，并迁移到新函数

**能力：c-isolation。前置：c-boundaries。**

规划用时约 1.25 小时：阅读 15 分钟、实践 45 分钟、验收 15 分钟。前两课检验单个数据处理函数；现在把输入来源也变成可控制的条件。

## 来源

阅读 [The Mock Class](https://docs.python.org/3/library/unittest.mock.html#the-mock-class) 中 `return_value`、`side_effect`、`assert_called_once_with` 的说明。相关章节核对范围见 [resources.json](../resources.json)。不要求学完全部 mock/patch 功能。

## 核心机制

本地实验把 `loader` 作为函数参数传给 `mean_from_loader`。这样测试可以给它一个固定返回值的替身，而不必真实访问文件或网络。目标不是假装外部系统已经正常工作，而是把“数据来源的行为”和“收到数据后的统计逻辑”分开检查。

因此要同时问两个问题：结果是否符合约定？依赖是否以约定方式被调用？成功的替身测试不证明真实服务的认证、网络、序列化和数据格式一定正确；那些需要另外设计集成检查。

## 小例子

用一个简单替身返回固定问候语：

```python
from unittest.mock import Mock

provider = Mock(return_value="hello")
observed = provider()
provider.assert_called_once_with()
```

这个例子展示“固定输出”和“调用检查”两个观察点；它与课程里的分数统计练习不同，不能直接当作完成作业的答案。

## 你的主任务

给 `mean_from_loader` 传入替身，测试三种情况：返回有效分数、抛出 `TimeoutError`、返回不符合分数契约的数据。检查结果/异常，同时检查 loader 是否恰好被调用一次。整个任务不应发出网络请求。

## 迁移项目：中位数

在个人副本中新建 `median_from_loader`：loader 仍只调用一次，沿用分数归一化契约，但最后返回归一化数值的中位数。自己决定实现，允许查文档，不看一步步解答。

你需要为奇数个数、偶数个数、重复值、输入未排序、单个值、加载器异常分别设计独立测试。验收时说明它与平均数的行为差异，并给出一个两者确实不同的具体输入。

## 提示

先给一个手算得出结果的小序列，再添加与它不同的序列。不要直接调用待测中位数函数来计算测试的预期。依赖异常传播与数据验证异常是两条不同路径。

## 最终产物与验收

提交测试、迁移函数和一段解释：mock 测试检查了什么，真实系统还有哪些方面没被检查。运行成功与超时两条路径、验证调用次数，独立通过奇偶长度的中位数测试，再由实际证据更新进度。

本课不附中位数任务的完整答案。它是一道需独立完成的验收题，不是遗漏的课程正文。示例 `progress.json` 不会因为本文件被阅读就自动标记通过。
